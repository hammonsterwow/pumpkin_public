# LRS-150F-5 전원 연결·구매 실행안

Pumpkin 로봇의 서보 9개 전원부를 실제로 조립하기 위한 **구매·수량·연결 실행표**입니다.

- 안전·전체 구조: [`LRS-150F-5_CONNECTION_GUIDE.md`](./LRS-150F-5_CONNECTION_GUIDE.md)
- WAGO/GND 버스 상세: [`SERVO_POWER_WAGO_MAP.md`](./SERVO_POWER_WAGO_MAP.md)
- 서보 ID/PCA9685 채널: [`MOTORS.md`](./MOTORS.md)
- 압착단자 규격: [`TERMINAL_PURCHASE_GUIDE.md`](./TERMINAL_PURCHASE_GUIDE.md)

> [!DANGER]
> 220 V AC 입력부는 플러그를 완전히 분리한 상태에서 작업하고, 최초 전원 인가는 경험 있는 작업자 또는 자격 있는 기술자의 검토를 받습니다.

---

## 1. 현재 확정 구조

```text
220 V AC
  ↓
접지형 C13 케이블
  ↓
0717-2SCQ
  ├─ LOAD L → 갈색 VCTF 0.75SQ → LRS AC/L
  ├─ LOAD N → 파랑 VCTF 0.75SQ → LRS AC/N
  └─ PE     → 녹/황 VCTF 0.75SQ → LRS FG
  ↓
MEAN WELL LRS-150F-5, 5 V / 22 A / 110 W

+V → 빨강 2.5SQ → 6구 ATO/ATC 퓨즈박스
  ├─ F1  5 A → 1.0SQ → WAGO_P_F1_NECK  → 목 MG996R ×2 +5 V
  ├─ F2 10 A → 1.5SQ → WAGO_P_F2_DS    → DS3218 ×2 +5 V
  ├─ F3  5 A → 1.0SQ → WAGO_P_F3_MG    → 팔 MG996R ×2 +5 V
  ├─ F4  5 A → 1.0SQ → WAGO_P_F4_MG90S → MG90S ×3 +5 V
  ├─ F5      → 예비, 퓨즈 미장착
  └─ F6      → 예비, 퓨즈 미장착

-V → 검정 2.5SQ → SMG TYE-TB003 GND 버스
  ├─ G1 → 1.0SQ → WAGO_G_F1_NECK  → 목 MG996R ×2 GND
  ├─ G2 → 1.5SQ → WAGO_G_F2_DS    → DS3218 ×2 GND
  ├─ G3 → 1.0SQ → WAGO_G_F3_MG    → 팔 MG996R ×2 GND
  ├─ G4 → 1.0SQ → WAGO_G_F4_MG90S → MG90S ×3 GND
  ├─ G5 → 0.5~0.75SQ → PCA9685 GND
  └─ G6 → 0.5~0.75SQ → ESP32 GND

ESP32 3.3 V/SDA/SCL → PCA9685 VCC/SDA/SCL
PCA9685 CHx Signal   → 각 서보 Signal
```

**PCA9685 V+는 서보 9개의 전원 분배에 사용하지 않습니다.**

## 2. 퓨즈 최종 조립표

현재 실제 사용 가능한 퓨즈 규격을 반영한 조립 기준입니다.

| 회로 | 장착 퓨즈 | 연결 부하 | 분기선 |
|---|---:|---|---|
| F1 | **5 A** | MG996R 목 ×2 | 빨강 1.0SQ |
| F2 | **10 A** | DS3218 ×2 | 빨강 1.5SQ |
| F3 | **5 A** | 팔 MG996R ×2 | 빨강 1.0SQ |
| F4 | **5 A** | MG90S ×3 | 빨강 1.0SQ |
| F5 | 미장착 | 예비 | - |
| F6 | 미장착 | 예비 | - |

### 실제 준비할 DC 퓨즈

- 장착용: **5 A ×3, 10 A ×1**
- 예비 권장: 5 A ×2 이상, 10 A ×1 이상
- 3 A와 7.5 A는 현재 조립 기준에서 사용하지 않음
- 15 A/20 A는 현재 F1~F4에 사용하지 않음

F2/F4는 실제 피크전류와 하네스 굵기 확인 후 재검토합니다.

## 3. WAGO 최종 사용 수량

현재 준비 계획의 WAGO를 **총 8개 모두 사용**합니다.

| 모델 | 수량 | 사용 |
|---|---:|---|
| WAGO `221-413` | **3개** | F1, F2, F3의 +5 V 분배 |
| WAGO `221-415` | **5개** | F4 +5 V 1개 + F1~F4 GND 4개 |

### +5 V용 WAGO 4개

| ID | 모델 | 연결 |
|---|---|---|
| `WAGO_P_F1_NECK` | 221-413 | F1 → 목 MG996R_01/02 빨간선 |
| `WAGO_P_F2_DS` | 221-413 | F2 → DS3218_01/02 빨간선 |
| `WAGO_P_F3_MG` | 221-413 | F3 → MG996R_03 + MG996R_04 빨간선 |
| `WAGO_P_F4_MG90S` | 221-415 | F4 → MG90S_01/02/03 빨간선, 1포트 비움 |

### GND용 WAGO 4개

| ID | 모델 | 연결 |
|---|---|---|
| `WAGO_G_F1_NECK` | 221-415 | G1 → 목 MG996R_01/02 GND |
| `WAGO_G_F2_DS` | 221-415 | G2 → DS3218_01/02 GND |
| `WAGO_G_F3_MG` | 221-415 | G3 → MG996R_03 + MG996R_04 GND |
| `WAGO_G_F4_MG90S` | 221-415 | G4 → MG90S_01/02/03 GND |

WAGO 내부 포트는 모두 공통이므로 물리적인 입력/출력 방향은 없습니다. 표에서는 조립 편의를 위해 공급선을 첫 포트로 정합니다.

### Fritzing에서 그릴 때

- 퓨즈박스 → + WAGO: **빨강**
- + WAGO → 서보 VCC: **빨강**
- GND 버스 → GND WAGO: **검정**
- GND WAGO → 서보 GND: **검정/갈색**
- PCA9685 → 서보 Signal: **노랑/주황**

따라서 `퓨즈박스 → WAGO 한 포트 → 나머지 포트에서 같은 그룹 서보들로 분기`하는 현재 연결 방식은 맞습니다. 단, +5 V를 나타내는 선은 WAGO 이후에도 빨간색으로 통일합니다.

## 8. 서보 하네스 제작

원래 서보 케이블을 직접 자르지 않고 JR/Futaba 연장선 9개를 가공합니다.

```text
연장선 빨간선       → 해당 +5 V WAGO
연장선 갈색/검정선  → 해당 GND WAGO
연장선 노랑/주황선  → 해당 PCA9685 CH Signal
```

- PCA9685 V+에는 최종 서보 전원을 연결하지 않습니다.
- PCA9685 채널 GND를 서보 고전류 귀환 경로로 사용하지 않습니다.
- 가공 후 각 심선을 열수축 튜브로 절연하고 스트레인 릴리프를 적용합니다.
- 서보/연장선의 실제 핀 순서는 전원 투입 전 확인합니다.

## 9. 실제 조립 순서

1. AC 플러그 완전 분리
2. 0717-2SCQ LINE/LOAD/N/PE와 퓨즈·스위치 연속성 확인
3. 0717 → LRS AC/L·AC/N·FG 연결
4. LRS +V → 2.5SQ 빨강 → 퓨즈박스 COMMON + 연결
5. LRS -V → 2.5SQ 검정 → GND 버스 MAIN 연결
6. 퓨즈박스에 F1~F6 라벨 부착
7. GND 버스에 G1~G6 라벨 부착
8. F1~F4 → +5 V WAGO 4개 연결
9. G1~G4 → GND WAGO 4개 연결
10. 서보 9개의 빨간선/GND를 각각 지정 WAGO에 연결
11. PCA9685 Signal을 각 지정 CH에 연결
12. G5 → PCA9685 GND, G6 → ESP32 GND 연결
13. ESP32 → PCA9685 VCC/SDA/SCL 연결
14. F1 5 A, F2 10 A, F3 5 A, F4 5 A 장착
15. F5/F6은 비워 둠
16. 무전원 상태 단락·극성·압착·당김 확인 후 시험
