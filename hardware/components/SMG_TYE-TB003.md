# SMG TYE-TB003 6단자 전원 분배 블록

Pumpkin 로봇의 5 V 서보 전원 시스템에서 **공통 GND(-V)를 분배**하기 위한 검정색 6단자 버스바입니다. 이 부품은 퓨즈 기능이 없는 단순 공통 전위 분배 블록이므로, 플러스 라인의 분기별 과전류 보호는 별도의 ATO/ATC 퓨즈박스가 담당합니다.

## 프로젝트 적용

- 적용 위치: `MEAN WELL LRS-150F-5 -V`와 각 서보·제어보드 GND 사이
- 선택 모델: **SMG TYE-TB003, 검정 6단자형**
- 프로젝트 사용 전압: `5 V DC`
- 프로젝트 최대 전원 정격: `22 A` (`LRS-150F-5` 기준)
- 판매 페이지 표시 정격 `48 V DC / 150 A`보다 프로젝트 조건이 낮아 정격상 여유가 있음
- 검정색 제품을 GND 전용으로 사용하고 플러스 배선에는 사용하지 않음

```text
LRS-150F-5 -V
    │ 검정 2.5SQ/AWG12
    ▼
TYE-TB003 대형 메인 스터드
    ├── 1.0SQ/AWG16 → 목 MG996R ×2 GND WAGO
    ├── 1.5SQ/AWG14 → 팔 대형 서보 ×4 GND WAGO
    ├── 1.0SQ/AWG16 → MG90S ×3 GND WAGO
    ├── 0.5~0.75SQ → PCA9685 GND
    ├── 0.5~0.75SQ → ESP32 GND
    └── 예비 1회로
```

두 개의 대형 스터드와 여섯 개의 소형 단자가 모두 같은 금속 버스에 연결된 구조로 보이지만, 실제 제품 수령 후 멀티미터 연속성 시험으로 확인합니다.

## BR-950S 고정식 단자대와의 차이

비룡전자 `BR-950S`는 외형상 여러 나사 단자가 나란히 있어 비슷해 보이지만, **공통 전원 분배용 버스바가 아니라 서로 분리된 5개의 회로를 연결하는 고정식 단자대**입니다.

| 항목 | SMG TYE-TB003 | 비룡전자 BR-950S |
|---|---|---|
| 기본 역할 | 하나의 공통 전원을 여러 갈래로 분배하는 버스바 | 선과 선을 1:1로 연결하는 5핀 단자대 |
| 내부 전기 구조 | 대형 스터드와 여러 분기 단자가 하나의 공통 금속 버스로 연결되는 구조로 보임 | 인접 단자끼리 자동으로 공통 연결되지 않는 독립 회로 구조 |
| 표시 정격 | 48 V DC / 150 A | 250 V / 20 A |
| 허용 전선 | 메인 2.5SQ와 분기 1.0~1.5SQ 적용 후보 | 판매 표시 `AWG16~22` |
| 메인 입력 | 대형 스터드 2개 | 별도 대형 메인 입력 없음 |
| 분기 수 | 소형 분기 6개 | 독립 5회로 |
| 보호 구조 | 투명 절연·방진 커버와 절연 바닥 | 일반 장벽형 단자대, 전체 보호 커버 없음 |
| 설치 용도 | 자동차·선박 등 비교적 큰 DC 전류 분배 | 제어선·저전류 배선의 중계·정리 |
| 표시 가격 | 12,000원 | 1,200원 |

가격 차이는 주로 다음 구조 차이에서 발생합니다.

1. `TYE-TB003`에는 큰 전류를 전달하는 두꺼운 공통 금속 버스가 들어가며, `BR-950S`는 소형 독립 단자 5쌍으로 구성됩니다.
2. `TYE-TB003`은 메인 2.5SQ 전선을 체결하는 대형 스터드와 여러 분기 단자를 제공하지만, `BR-950S`에는 고전류 메인 입력 단자가 없습니다.
3. `TYE-TB003`은 투명 커버, 절연 바닥, 스테인리스 체결부 등 자동차·선박용 분배 구조를 갖추고 있습니다.
4. 판매 표시상 전류 정격이 `150 A`와 `20 A`로 크게 다릅니다. 다만 `TYE-TB003`의 150 A는 공식 데이터시트가 아닌 판매처 표시값이므로 실물 발열 시험이 필요합니다.
5. `TYE-TB003`은 해외구매·주문제작 취급이고 `BR-950S`는 단순 범용 단자대이므로 유통비 차이도 포함됩니다.

### Pumpkin 적용 판단

- `BR-950S`는 그대로 사용하면 5개 단자가 공통 GND가 아니므로 **TYE-TB003의 대체품이 아닙니다**.
- 점퍼선을 추가하여 모든 회로를 공통으로 묶는 방법도 가능하지만, 판매 표시가 `20 A`, `AWG16~22`이고 메인 2.5SQ 연결이 곤란하여 LRS-150F-5의 22 A 서보 전원 GND 버스로는 권장하지 않습니다.
- `BR-950S`는 센서 신호선, 저전류 로직 전원, 작은 부하의 1:1 중계 단자로 사용하는 편이 적합합니다.
- Pumpkin의 서보 공통 GND에는 현재 계획대로 `TYE-TB003` 또는 **총 정격 30 A 이상이며 2.5SQ 메인 입력과 1.0/1.5SQ 분기 연결을 지원하는 동급 버스바**를 사용합니다.

## 판매 설명의 확인 필요 사항

판매 설명에는 베이스가 `nylon fiber reinforced`라고 적혀 있으나 사양표에는 `ABS`라고 적혀 있어 재질 정보가 일치하지 않습니다. 또한 제품 제목은 12 V용으로 표시되지만 사양표의 최대 전압은 48 V DC로 표시됩니다. Pumpkin은 5 V에서 사용하므로 전압 범위에는 문제가 없지만, 문서에는 두 표기를 구분하여 남깁니다.

## 기구 설계 반영값

- 본체 설치 공간: 최소 `121 × 42 mm`
- 판매 이미지 기준 높이: 약 `20 mm`이나, 대형 스터드와 투명 커버를 포함한 실제 최대 높이는 수령 후 측정
- 양 끝 고정홀 2개를 이용해 난연 전원함 내부에 고정
- 커버를 위로 분리할 수 있도록 상부 작업 공간 확보
- 메인 2.5SQ 전선과 분기 링단자의 굽힘 반경을 고려해 측면 여유 확보
- 노출된 금속 버스와 스터드는 투명 커버를 장착한 상태로 사용

## 안전 및 사용 원칙

- 이 부품은 **GND(-V) 공통 분배 전용**으로 사용합니다.
- 퓨즈가 내장되지 않은 버스바이므로 과전류 보호 기능이 없습니다.
- 플러스 분기는 반드시 별도의 6구 ATO/ATC 퓨즈박스를 통과시킵니다.
- `150 A`는 판매 페이지상의 부품 한계 정격이며 Pumpkin에서 흘려도 되는 목표 전류가 아닙니다.
- 시스템 전체 전류는 LRS-150F-5 정격인 22 A 이내로 제한합니다.
- 대형 스터드 두 개 중 하나에 LRS -V를 연결하고, 다른 하나는 필요하지 않으면 절연 캡을 유지한 채 비워 둡니다.
- 모든 링단자는 전선 굵기와 볼트 지름에 맞춰 압착하고 체결 후 당김 시험을 수행합니다.
- 부하 시험 중 메인 스터드, 소형 나사, 버스바와 링단자의 전압 강하 및 발열을 측정합니다.
- GND 버스와 퓨즈박스는 같은 난연 전원함 내부에 고정하되 서로 접촉하지 않도록 배치합니다.

## 구매 전 추가로 필요한 상세 사양

다음 정보가 판매처 또는 데이터시트에서 확인되면 링단자와 기구 설계를 확정할 수 있습니다.

1. 대형 메인 스터드의 정확한 나사 규격: `M5` 또는 `M6`, 나사 피치와 유효 체결 길이
2. 6개 소형 분기 나사의 정확한 규격: `M4` 여부, 나사 피치와 유효 체결 길이
3. 대형 스터드와 소형 나사의 권장 체결 토크
4. 양 끝 장착홀의 지름, 홀 중심 간 거리, 권장 고정 나사 규격
5. 투명 커버 장착 상태의 실제 최대 높이와 전선 인출 방향
6. 두 대형 스터드와 6개 소형 단자가 모두 전기적으로 공통인지 확인한 내부 결선도
7. 150 A 연속 정격의 시험 조건, 허용 온도, 버스바 재질·두께와 인증 정보
8. 6단자 검정형의 정확한 구성품과 실제 중량이 80 g인지 확인
