# 6구 ATO/ATC 퓨즈박스

Pumpkin 로봇의 5 V 서보 전원 플러스 분배와 분기별 과전류 보호에 사용하는 6회로 자동차용 블레이드 퓨즈박스입니다.

## 프로젝트 적용

- 적용 위치: `MEAN WELL LRS-150F-5 +V`와 서보 전원 분기 사이
- 선택 규격: **6구 공통 입력형 ATO/ATC 퓨즈박스**
- 사용 회로: **F1~F4 4개**
- 예비 회로: **F5~F6 2개, 퓨즈 미장착**
- GND는 본 제품을 거치지 않고 별도 GND 버스로 분배

```text
LRS-150F-5 +V
    │ 2.5SQ
    ▼
M5 공통 입력 스터드
    │
6구 ATO/ATC 퓨즈박스
    ├── F1 5 A  → 목 MG996R ×2
    ├── F2 10 A → DS3218 ×2
    ├── F3 5 A  → 팔 MG996R ×2
    ├── F4 5 A  → MG90S ×3
    ├── F5      → 예비, 퓨즈 미장착
    └── F6      → 예비, 퓨즈 미장착
```

## 최종 회로 배정

| 퓨즈 ID | 회로 | 적용값 | 연결 서보 ID | PCA9685 채널 |
|---|---:|---:|---|---|
| `FUSE_SERVO_NECK` | F1 | **5 A** | `SERVO_MG996R_01`, `SERVO_MG996R_02` | CH0, CH1 |
| `FUSE_SERVO_ARM_DS` | F2 | **10 A** | `SERVO_DS3218_01`, `SERVO_DS3218_02` | CH4, CH5 |
| `FUSE_SERVO_ARM_MG` | F3 | **5 A** | `SERVO_MG996R_03`, `SERVO_MG996R_04` | CH6, CH7 |
| `FUSE_SERVO_ARM_MG90S` | F4 | **5 A** | `SERVO_MG90S_01`, `SERVO_MG90S_02`, `SERVO_MG90S_03` | CH8, CH9, CH10 |
| `FUSE_SERVO_SPARE_1` | F5 | 미장착 | - | - |
| `FUSE_SERVO_SPARE_2` | F6 | 미장착 | - | - |

### 현재 퓨즈값 결정 근거

- **F1 5 A:** `MG996R` 기록 stall current 1.4 A/개, 2개 합계 2.8 A이며 기존 목 분기 시험 시작값이 5 A였습니다.
- **F2 10 A:** `DS3218` 개별 stall current는 아직 실측 전입니다. 원래 7.5 A를 중간값으로 검토했지만 실제 보유·구매 가능한 퓨즈가 5 A 또는 10 A이므로 **10 A**를 적용합니다. F2 분기선은 1.5SQ/AWG14이고, 팔 전체의 기존 `5 V / 10 A` 설계 참고값을 고려합니다. 실제 DS3218 2개 동시 동작 피크를 측정한 뒤 유지 여부를 재검토합니다.
- **F3 5 A:** `MG996R` 기록 stall current 1.4 A/개, 2개 합계 2.8 A이므로 5 A를 적용합니다.
- **F4 5 A:** 원래 MG90S 3개 분기의 시험 시작값으로 3 A를 검토했지만 실제 보유 퓨즈가 5 A 또는 10 A뿐이므로 **5 A**를 적용합니다. 두 선택지 중 더 작은 값을 사용하며 실제 3개 동시 동작 피크전류를 측정한 뒤 유지 여부를 재검토합니다.
- F2와 F4는 개별 서보 피크전류 실측값이 없으므로 **현재 프로젝트 배선 기준값이며 실측 후 재검토 대상**입니다.

## 구성품

판매 이미지에 표시된 구성품은 다음과 같습니다.

| 구성품 | 수량 |
|---|---:|
| 5 A 퓨즈 | 2개 |
| 10 A 퓨즈 | 2개 |
| 15 A 퓨즈 | 4개 |
| 20 A 퓨즈 | 4개 |
| 고정 나사 | 4개 |
| 회로명 스티커 | 40장 |
| 절연 링 터미널 | 10개 |

현재 프로젝트에는 **5 A 3개, 10 A 1개**가 필요합니다. F2에는 10 A, F1·F3·F4에는 5 A를 사용합니다. 동봉 수량이 5 A 2개뿐이라면 **5 A 퓨즈 1개 이상을 추가로 준비**합니다. 15/20 A 퓨즈를 빈 회로나 F1/F3/F4에 임의로 사용하지 않습니다.

## 기구 설계 반영값

- 본체 평면 설치 공간: 최소 `85 × 70 mm`
- 전체 높이: 약 `35 mm`
- 커버 탈착과 퓨즈 교체를 위해 상부 여유 공간 확보
- 전선 굽힘 반경과 링단자 체결 공간을 포함하여 좌우·하단에 추가 여유 확보
- 고정 구멍의 정확한 위치와 나사 규격은 실물 수령 후 측정
- 실물 퓨즈박스에 `F1`~`F6` 라벨을 부착하고 `MOTORS.md`의 회로 번호와 일치시킴

## 안전 및 사용 원칙

- 본 제품은 **DC 플러스 라인 전용**으로 사용합니다.
- 5 V 시스템에서도 퓨즈박스 자체 전압 강하와 단자 발열을 측정합니다.
- 전체 100 A, 회로별 30 A 표시는 제품 한계값이며 프로젝트의 권장 사용 전류를 뜻하지 않습니다.
- LRS-150F-5의 정격 출력은 22 A이므로 시스템 전체 전류는 전원 정격을 넘기지 않습니다.
- 퓨즈는 배선 보호를 목적으로 하며, 각 분기 전선 허용전류보다 큰 값으로 선정하지 않습니다.
- 링단자는 해당 전선 굵기에 맞는 압착 공구로 체결하고, 체결 후 인장 시험을 수행합니다.
- 퓨즈박스와 GND 버스는 난연 전원함 안에 고정하고 노출 도체를 방지합니다.
- 퓨즈가 반복 단선되면 정격을 바로 올리지 말고 단락, 기구 걸림, 피크전류, 전압강하와 단자 발열을 확인합니다.

## 실물 수령 후 확인표

- [ ] 실제 제품이 6구 공통 입력형인지 확인
- [ ] 본체 외형 `85 × 70 × 35 mm` 확인
- [ ] 공통 입력 스터드가 실제 M5인지 확인
- [ ] 분기 출력 나사가 실제 M4인지 확인
- [ ] 고정홀 위치·지름·권장 나사 길이 측정
- [ ] 투명 커버 간섭과 퓨즈 교체 공간 확인
- [ ] LED가 단선 퓨즈 표시 방식인지 동작 확인
- [ ] 동봉 링단자의 적용 전선 굵기 확인
- [ ] 메인 2.5SQ와 분기 1.0/1.5SQ 링단자 체결 시험
- [ ] F1~F6 라벨 부착
- [ ] F1=5 A, F2=10 A, F3=5 A, F4=5 A 확인
- [ ] F5·F6 퓨즈 미장착 확인
- [ ] 무부하·부분 부하·전체 부하에서 입력/출력 전압 강하 측정
- [ ] 각 단자와 퓨즈 접점의 발열 측정
- [ ] DS3218·MG90S 피크전류 측정 후 F2/F4 유지 여부 결정

## 비고: 12구형 이미지

제공된 이미지 중 `50 × 120 × 52 mm`로 표시된 제품은 12구형으로 보이며, 현재 프로젝트의 구매 기준인 6구형과 다른 제품입니다. Pumpkin에는 현재 4개 서보 전원 분기를 사용하므로 6구형을 유지합니다.
