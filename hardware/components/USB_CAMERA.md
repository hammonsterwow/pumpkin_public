# USB Camera — Shoulder-mounted vision sensor

## 프로젝트 적용 상태

- 부품: `1080 Full HD Auto Focus USB Camera`
- 용도: 사용자 접근 감지, 얼굴 인식, 고개 끄덕임/좌우 흔들기 등 비전 입력
- 장착 위치: **로봇 어깨부에 고정 장착**
- 장착 방식: **머리/목 관절과 분리된 고정형 카메라**
- 상태: 실제 하드웨어 배치 기준 확정
- 기록일: 2026-08-09

## 중요 하드웨어 기준

> 카메라는 로봇 머리에 장착되어 있지 않다. 카메라는 어깨에 고정되어 있으며, 목의 상하·좌우 회전과 카메라의 자세는 서로 독립적이다.

따라서 소프트웨어와 테스트에서 다음 전제를 사용한다.

1. 로봇이 `NOD`, `DOUBLE_NOD`, `SHAKE`, `TURN_LEFT`, `TURN_RIGHT` 등의 머리 동작을 수행해도 카메라 자체가 머리와 함께 회전한다고 가정하지 않는다.
2. 사용자 얼굴·고개 제스처 인식은 어깨에 고정된 카메라 좌표계를 기준으로 처리한다.
3. 비전 로직이나 문서에서 `head-mounted camera`, `머리 장착 카메라`, `머리 움직임 때문에 카메라 영상이 함께 움직임`과 같은 설명을 사용하지 않는다.

## 연결

```text
로봇 어깨부
  └── USB Camera (고정)
        └── USB / UVC
              └── Jetson Orin Nano 또는 유전원 USB 허브
```

## 관련 하드웨어 ID

`hardware/components.yaml`의 카메라 항목:

```text
VISION_CAMERA_USB_FHD
```

정확한 제조사/세부 모델명은 현재 미확정이며, 장착 위치와 역할은 위 내용으로 확정한다.
