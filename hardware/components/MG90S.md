# TowerPro 호환 MG90S 서보모터

한쪽 팔의 손목·손·보조 제스처에 사용할 MG90S 180° 서보모터 3개의 사양과 시험 항목을 정리합니다.

> 아래 사양은 판매 페이지 표기 기준입니다. 실제 구매 후 제품 라벨, 회전 범위, 무부하 전류와 정지전류를 확인합니다.

## 구매 계획

| 항목 | 내용 |
|---|---|
| 제품명 | TowerPro 호환 MG90S 서보모터 |
| 수량 | 3개 구매 예정 |
| 최종 용도 | 한쪽 팔의 경량 관절 3개 |
| 제어 장치 | Voltly PCA9685 `VLT-MD032` |
| 최종 전원 | MEAN WELL LRS-150F-5 기반 5 V 서보 레일 |
| PCA9685 채널 초안 | CH8, CH9, CH10 |

## 판매 페이지 사양

| 항목 | 사양 |
|---|---|
| 회전 범위 | 약 180° · 중앙 기준 좌우 약 90° |
| 동작 전압 | 4.8~6.0 V |
| 스톨 토크 | 4.8 V에서 1.8 kgf·cm, 6 V에서 2.2 kgf·cm |
| 동작 속도 | 4.8 V에서 0.10 s/60°, 6 V에서 0.08 s/60° |
| 데드밴드 | 5 µs |
| 무게 | 13.4 g |
| 본체 크기 | 약 22.5 × 12 × 35.5 mm |
| 제어 방식 | 50 Hz PWM, 주기 20 ms |
| 펄스 폭 | 약 1~2 ms |
| 중앙 위치 | 약 1.5 ms |
| 배선 색상 | PWM: 주황색, VCC(+): 빨간색, GND(-): 갈색 |
| 평상시·정지전류 | 판매 페이지 미확인, 구매 후 실측 필요 |

## PWM 기준

```text
약 1.0 ms  → -90° 방향
약 1.5 ms  → 중앙 0°
약 2.0 ms  → +90° 방향
주기 20 ms → 50 Hz
```

실제 제품의 기계적 끝점은 이론값과 다를 수 있으므로 최초 시험은 좁은 펄스 범위에서 시작합니다.

## 장착 원칙

MG90S는 MG996R·MG995·DS3218보다 작고 가볍지만 토크가 낮습니다. 팔 전체를 직접 지지하는 어깨나 팔꿈치 주 관절에는 사용하지 않고 다음과 같은 경량 관절에 배정합니다.

- 손목 방향 조정
- 손 또는 손가락 형태의 간단한 동작
- 인사·방향 안내를 위한 보조 제스처

실제 팔 기구에서 토크가 부족하면 관절의 무게와 링크 길이를 줄이거나 더 큰 서보로 변경합니다.

## 연결 계획

```text
ESP32 ── I2C ── PCA9685_MAIN ── PWM ── MG90S 3개
                          │
LRS-150F-5 ── DC 분배 단자대 ── +5 V / GND
```

- PWM 신호는 PCA9685에서 공급합니다.
- 고전류 전원은 PCA9685의 작은 단자 하나를 통과시키지 않고 DC 분배 단자대에서 공급합니다.
- MG90S 3개는 팔 경량 관절용 별도 분기로 묶습니다.
- PCA9685 GND, ESP32 GND와 LRS-150F-5의 `-V`를 공통 연결합니다.
- 서보 전원은 ESP32나 Jetson에서 직접 공급하지 않습니다.
