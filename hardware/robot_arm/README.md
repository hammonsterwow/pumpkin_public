# 3D 프린팅 로봇팔 제작 및 제어 전환 계획

Pumpkin 로봇에 장착할 한쪽 로봇팔의 기구 제작, 부품 구성, 전원, ESP32·PCA9685 제어 전환과 ROS2 연동 계획을 정리합니다.

## 1. 최종 결정

- 로봇팔 기구부는 MakerWorld의 공개 모델을 수정하지 않고 원본 STL 그대로 출력합니다.
- 팀에서 새로운 팔 기구를 직접 CAD 설계하지 않습니다.
- 원본의 Arduino Uno/Mega 직접 제어 방식은 사용하지 않습니다.
- 제어 구조는 `Jetson Orin Nano → ESP32 → PCA9685 → 서보모터`로 변경합니다.
- 로봇팔은 한쪽만 장착합니다.
- 원본 로봇팔 서보 7개와 목 서보 2개를 합쳐 총 9개의 서보를 제어합니다.

## 2. 원본 모델

- 모델명: **Robotic Arm with Servo & Arduino**
- 제작자: **Emre Kalem**
- 원본 페이지: <https://makerworld.com/ko/models/1134925-robotic-arm-with-servo-arduino?from=search#profileId-1135927>
- 참고 출력 설정: 0.2 mm 레이어, 벽 3개, infill 20%

### STL 관리 원칙

원본 STL과 원본 파생 파일은 이 저장소에 다시 업로드하지 않습니다. 출력할 팀원은 반드시 위 MakerWorld 원본 페이지에서 직접 파일을 내려받습니다.

이 저장소에는 다음 자료만 관리합니다.

- 원본 링크와 출처
- 구매 부품 목록
- 조립 및 시험 기록
- 프로젝트에서 직접 작성한 ESP32 펌웨어
- PCA9685 채널과 안전 각도
- Jetson·ROS2 연동 코드와 명령 규격
- 직접 촬영한 완성품 사진

## 4. 최종 서보 구성

### 로봇팔 7개

원본 BOM은 대형 관절에 MG995 또는 MG996R을 허용하지만, Pumpkin 최종 구성은 현재 기구·전원 계획에 맞춰 다음과 같이 확정합니다.

- DS3218 180° × 2
- MG996R 180° × 2
- MG90S 180° × 3

### 목 2개

- MG996R 180° × 2

### 총 수량

- MG996R × 4
- DS3218 × 2
- MG90S × 3
- 총 9개

예비품:

- MG995 × 2
- SG90 × 1

현재 구성에서 CH7은 `SERVO_MG996R_04`를 사용하며, 기존 `SERVO_MG995_01`은 장착 대상에서 제외하고 예비품으로 보관합니다.

## 5. 전체 제어 구조

```text
ROS2 decision/action 계층
        │
        │ /robot_action 또는 행동 명령
        ▼
Jetson Orin Nano
        │ USB Serial
        ▼
ESP32
        │ I2C
        ▼
PCA9685
        │ PWM
        ├── 목 서보 2개
        └── 로봇팔 서보 7개
```

### 역할 분담

#### Jetson Orin Nano

- 사용자 인식과 주문 대화 상태 판단
- 수행할 로봇 행동 선택
- ESP32에 행동 명령 전송
- ESP32의 완료·오류 상태 수신

#### ESP32

- USB Serial 명령 수신
- 동작 프리셋 선택
- 관절별 각도 제한 적용
- 급격한 이동을 막기 위한 보간 제어
- PCA9685 PWM 출력
- 동작 완료·오류 상태 회신

#### PCA9685

- 서보 9개의 PWM 신호 생성
- 서보 전력 공급 장치로 사용하지 않음

## 7. 전원 구조

최종 서보 전원은 **MEAN WELL LRS-150F-5, 5 V / 22 A / 110 W**를 사용합니다.

```text
LRS-150F-5
    ├── +V → 6구 ATO/ATC 퓨즈박스
    │          ├── F1 5 A  → 목 MG996R ×2
    │          ├── F2 10 A → DS3218 ×2
    │          ├── F3 5 A  → 팔 MG996R ×2
    │          └── F4 5 A  → MG90S ×3
    │
    └── -V → GND 버스
               ├── G1~G4 → 각 서보 그룹 GND
               ├── G5 → PCA9685 GND
               └── G6 → ESP32 GND
```

### 전원 원칙

- 서보 전원은 Jetson USB, ESP32의 5 V 핀 또는 3.3 V 핀에서 공급하지 않습니다.
- PCA9685 로직 `VCC`는 ESP32 3.3 V에 연결합니다.
- PCA9685의 `VCC`와 서보 전원 `V+`를 구분합니다.
- 서보 고전류는 PCA9685 보드의 작은 전원 단자 하나에 몰아 넣지 않고 퓨즈박스·WAGO 분배부에서 공급합니다.
- ESP32, PCA9685, LRS-150F-5와 모든 서보의 GND는 공통 연결합니다.
- 목, DS3218, 팔 MG996R, 팔 MG90S를 F1~F4 네 분기로 나누고 실제 측정값을 기록합니다.
- LRS-75-5와 LRS-150F-5 출력은 병렬로 연결하지 않습니다.

## 8. Jetson–ESP32 명령 규격 초안

초기에는 Jetson이 각 서보 각도를 직접 계속 전송하지 않고, 서비스 행동 이름을 ESP32에 전달합니다.

```text
ARM,HOME
ARM,GREETING
ARM,ORDER_CONFIRM
ARM,POINT_PICKUP
ARM,GRIP_OPEN
ARM,GRIP_CLOSE
ARM,STOP
```

ESP32는 각 행동에 필요한 관절 목표 각도를 프리셋으로 저장하고 천천히 이동시킵니다.

### 상태 응답 예시

```text
ARM,ACK,GREETING
ARM,DONE,GREETING
ARM,ERROR,LIMIT,CH5
ARM,STOPPED
```

ROS2 연동이 완료되면 명령의 송신 주체는 `arm_control_node`로 통일합니다.

## 9. 기본 동작 범위

| 동작 | 용도 |
|---|---|
| HOME | 전원 투입·대기 시 안전 기본 자세 |
| GREETING | 고객 접근 시 인사 동작 |
| ORDER_CONFIRM | 주문 확인 중 팔 제스처 |
| POINT_PICKUP | 음료 픽업 위치 안내 |
| GRIP_OPEN | 집게 열기 시험 및 시연 |
| GRIP_CLOSE | 집게 닫기 시험 및 시연 |
| STOP | 즉시 목표 이동 중단 |

원본 로봇팔은 물체 파지가 가능하지만, Pumpkin 프로젝트의 필수 목표는 정밀 작업이 아니라 **인사·주문 확인·방향 안내 제스처**입니다. 집게 기능은 기구 시험 후 확장 기능으로 사용합니다.

## 10. 제작 순서

1. MakerWorld 원본 페이지에서 STL과 조립 영상을 확인합니다.
2. 원본 STL을 수정하지 않고 출력합니다.
3. 출력물의 깨짐, 휨, 서보 삽입부와 볼트 구멍을 확인합니다.
4. 모든 서보를 기구에 장착하기 전에 단품 시험합니다.
5. 서보를 중립 위치로 이동한 뒤 전원을 끄고 서보혼을 조립합니다.
6. 베어링과 M3 볼트를 사용해 원본 순서대로 기구를 조립합니다.
7. 팔을 로봇 몸통에 장착하기 전에 별도 작업대에서 시험합니다.
8. CH4부터 CH10까지 서보를 한 개씩 연결합니다.
9. 각 채널의 회전 방향, 중립값, 최소·최대 안전값을 기록합니다.
10. HOME 자세를 먼저 구현합니다.
11. 관절을 한 개씩 움직인 뒤 여러 관절의 순차 동작을 시험합니다.
12. Jetson–ESP32 USB Serial 통신을 연결합니다.
13. ROS2 행동 명령과 팔 동작을 연동합니다.
14. 인사·주문 확인·픽업 안내 시나리오를 반복 시험합니다.
15. 30분 이상 반복 동작 후 전압 강하, 발열, 떨림과 케이블 끼임을 확인합니다.

## 12. 안전 주의사항

- 서보혼을 잘못된 각도에서 조립하면 전원 투입 즉시 기구가 충돌할 수 있습니다.
- 서보를 기구에 장착하기 전 반드시 중립 위치를 확인합니다.
- 처음부터 0~180° 전체 범위를 움직이지 않습니다.
- 각 관절을 5° 이하의 작은 단위로 움직이며 안전 범위를 찾습니다.
- 고토크 관절과 집게 사이에 손가락을 넣지 않습니다.
- 이상 소음, 떨림, 정지 상태의 과전류가 발생하면 즉시 서보 전원을 차단합니다.
- ESP32 통신이 끊기거나 잘못된 명령을 받았을 때 현재 동작을 중단하도록 타임아웃을 구현합니다.
- 전원 복구 후에는 자동으로 큰 동작을 실행하지 않고 HOME 자세 복귀 전 점검 절차를 거칩니다.
