# LRS-150F-5 최종 연결·안전·시험 가이드

Pumpkin 고정형 로봇의 목·팔 서보 9개 전원 배선을 위한 **최종 구조 기준 문서**입니다.

이 문서에서 다음을 관리합니다.

- MEAN WELL LRS-150F-5 공식 전원 조건
- Inalways 0717-2SCQ AC 입력 구조
- 6구 ATO/ATC 퓨즈박스 F1~F6 배정
- SMG TYE-TB003 GND 버스 G1~G6 배정
- WAGO 221-413/221-415의 실제 연결 위치
- PCA9685와 서보 전원·GND·Signal 분리 원칙
- 최초 전원 투입과 분기별 시험 순서

세부 서보 ID/PCA9685 채널은 [`MOTORS.md`](./MOTORS.md), 실제 WAGO 포트별 연결은 [`SERVO_POWER_WAGO_MAP.md`](./SERVO_POWER_WAGO_MAP.md), 구매 수량은 [`LRS-150F-5_CONNECTION_PLAN_FROM_CHAT.md`](./LRS-150F-5_CONNECTION_PLAN_FROM_CHAT.md)를 같이 봅니다.

> [!DANGER]
> LRS 입력에는 220 V AC가 직접 연결됩니다. AC 배선은 플러그를 완전히 분리한 상태에서 작업하고, 최초 전원 인가는 경험 있는 작업자 또는 자격 있는 기술자의 검토를 받습니다.

> [!WARNING]
> LRS-150F-5의 5 V 출력은 최대 22 A입니다. 저전압이라도 합선 시 전선·단자·커넥터가 빠르게 과열될 수 있으므로 퓨즈, 적절한 전선 굵기, 절연, 압착, 고정이 필요합니다.

## 1. 최종 로봇 전원 조건

- 고정형 로봇
- 팔 1개, 목 2축
- 최종 장착 서보 9개
- 목: MG996R ×2
- 팔: DS3218 ×2 + MG996R ×2 + MG90S ×3
- 서보 전원: MEAN WELL `LRS-150F-5`
- 서보 제어: ESP32 + PCA9685
- Jetson, 5인치 LCD, USB 허브는 각자의 전용 전원을 유지

## 2. LRS-150F-5 공식 기준

| 항목 | 값 |
|---|---:|
| AC 입력 | `85~264 V AC`, `47~63 Hz` |
| 230 V 입력전류 | `1.7 A typ.` |
| 230 V 냉간 돌입전류 | `60 A typ.` |
| DC 출력 | `5 V / 22 A` |
| 정격 출력 | `110 W` |
| 출력 조정 범위 | `4.5~5.5 V` |
| 효율 | `85% typ.` |
| 외형 | `159 × 97 × 30 mm` |
| 단자 | M3.5 단자대 |
| 단자 체결 토크 | `8~10 kgf·cm` 약 `0.78~0.98 N·m` |
| 바닥 장착 | M3, 최대 삽입 3.0 mm |
| 측면 장착 | M3, 최대 삽입 5 mm |

LRS-150F-5는 5 V 형식에서 22 A, 110 W 출력입니다.

### LRS 단자 역할

| 표기 | 연결 |
|---|---|
| `AC/L` | 0717-2SCQ의 LOAD L |
| `AC/N` | 0717-2SCQ의 LOAD N |
| `FG` | C13 보호접지 PE |
| `-V` | 서보 시스템 DC GND |
| `+V` | 서보 시스템 +5 V |

`FG`는 보호접지이고 `-V`는 DC GND입니다. 프로젝트에서 둘을 임의로 점퍼하지 않습니다.

## 3. 0717-2SCQ AC 입력 구조

Inalways `0717-2SCQ`는 IEC C14 인렛, 2극 ON/OFF 스위치와 2개 퓨즈홀더가 결합된 AC 입력부입니다.

| 항목 | 값 |
|---|---:|
| 정격 | `10 A / 250 V AC` |
| 스위치 | Double Pole ON/OFF |
| 퓨즈홀더 | 2개 |
| 후면 탭 | `4.8 × 0.8 mm` Quick Disconnect |
| 패널 개구부 | `55.3(+0.2/0) × 27.5(+0.2/0) mm` |
| 고정홀 중심간 거리 | `65.0 ±0.15 mm` |
| 고정홀 | 2-M3 또는 Ø3.6 mm |

```text
220 V AC
  ↓
접지형 C13 케이블
  ↓
0717-2SCQ
  ├─ LOAD L → 갈색 VCTF 0.75SQ → LRS AC/L
  ├─ LOAD N → 파랑 VCTF 0.75SQ → LRS AC/N
  └─ PE     → 녹/황 VCTF 0.75SQ → LRS FG
```

- 0717 후면에는 4.8 mm 완전절연 암 평단자를 사용합니다.
- AC 퓨즈의 물리 크기·전류 정격·시간지연 특성은 실물 퓨즈 트레이와 LRS 돌입전류를 확인한 뒤 결정합니다.
- 사진의 위치만 믿지 말고 무전원 상태에서 연속성 측정으로 LINE/LOAD/스위치/퓨즈 경로를 확인합니다.

## 4. 최종 DC 전원 구조

### 4.1 +5 V 경로

```text
LRS-150F-5 +V
  │ 빨강 2.5SQ/AWG12
  ▼
6구 공통입력형 ATO/ATC 퓨즈박스
  ├─ F1  5 A → 빨강 1.0SQ → WAGO_P_F1_NECK  → 목 MG996R ×2 빨간선
  ├─ F2 10 A → 빨강 1.5SQ → WAGO_P_F2_DS    → DS3218 ×2 빨간선
  ├─ F3  5 A → 빨강 1.0SQ → WAGO_P_F3_MG    → 팔 MG996R ×2 빨간선
  ├─ F4  5 A → 빨강 1.0SQ → WAGO_P_F4_MG90S → MG90S ×3 빨간선
  ├─ F5      → 예비, 퓨즈 미장착
  └─ F6      → 예비, 퓨즈 미장착
```

### 4.2 GND 경로

**서보 9개의 GND는 모두 LRS `-V`와 연결된 GND 버스로 돌아갑니다.**

서보 GND 9가닥을 버스바에 각각 직접 연결하지 않고, 같은 전원 그룹끼리 WAGO로 묶은 뒤 WAGO에서 굵은 검정 분기선 한 가닥을 GND 버스로 연결합니다.

```text
LRS-150F-5 -V
  │ 검정 2.5SQ/AWG12
  ▼
SMG TYE-TB003 GND 버스
  ├─ G1 → 검정 1.0SQ → WAGO_G_F1_NECK  → 목 MG996R ×2 GND
  ├─ G2 → 검정 1.5SQ → WAGO_G_F2_DS    → DS3218 ×2 GND
  ├─ G3 → 검정 1.0SQ → WAGO_G_F3_MG    → 팔 MG996R ×2 GND
  ├─ G4 → 검정 1.0SQ → WAGO_G_F4_MG90S → MG90S ×3 GND
  ├─ G5 → 검정 0.5~0.75SQ → PCA9685 GND
  └─ G6 → 검정 0.5~0.75SQ → ESP32 GND
```

실물 GND 버스에는 `G1`~`G6` 라벨을 직접 붙여 문서 번호와 맞춥니다.

## 5. WAGO 연결 원칙

WAGO 221은 한 커넥터 안의 모든 포트가 서로 공통입니다. 따라서 별도의 입력 포트·출력 포트 방향은 없습니다. 조립 편의를 위해 이 문서에서는 첫 포트를 공급선으로 정해 표시합니다.

### 5.1 +5 V WAGO

| WAGO ID | 모델 | 연결 |
|---|---|---|
| `WAGO_P_F1_NECK` | 221-413 | F1 출력 + 목 MG996R_01 빨강 + MG996R_02 빨강 |
| `WAGO_P_F2_DS` | 221-413 | F2 출력 + DS3218_01 빨강 + DS3218_02 빨강 |
| `WAGO_P_F3_MG` | 221-413 | F3 출력 + MG996R_03 빨강 + MG996R_04 빨강 |
| `WAGO_P_F4_MG90S` | 221-415 | F4 출력 + MG90S_01/02/03 빨강, 1포트 비움 |

### 5.2 GND WAGO

| WAGO ID | 모델 | 연결 |
|---|---|---|
| `WAGO_G_F1_NECK` | 221-415 | GND 버스 G1 + 목 MG996R_01/02 GND |
| `WAGO_G_F2_DS` | 221-415 | GND 버스 G2 + DS3218_01/02 GND |
| `WAGO_G_F3_MG` | 221-415 | GND 버스 G3 + MG996R_03/MG996R_04 GND |
| `WAGO_G_F4_MG90S` | 221-415 | GND 버스 G4 + MG90S_01/02/03 GND |

현재 구매 계획을 그대로 쓰면 다음 8개를 모두 사용합니다.

```text
221-413 ×3 → F1/F2/F3 +5 V 분배
221-415 ×1 → F4 +5 V 분배
221-415 ×4 → F1/F2/F3/F4 GND 분배
────────────────────────────────
총 221-413 ×3 + 221-415 ×5
```

WAGO 221-413은 3-conductor, 221-415는 5-conductor 제품이며 최대 4 mm² 도체를 지원합니다. 프로젝트의 1.0SQ와 1.5SQ 분기선은 이 범위 안입니다.

### Fritzing 선 색상 기준

회로 기능을 눈으로 구분하기 위해 최종 도면에서는 다음 색으로 통일합니다.

- **빨강:** +5 V 전원. 퓨즈박스 → + WAGO → 서보 빨간선
- **검정 또는 갈색:** GND. GND 버스 → GND WAGO → 서보 GND
- **노랑/주황:** PWM Signal. PCA9685 → 서보 Signal

따라서 Fritzing에서 퓨즈박스에서 WAGO로 한 가닥, WAGO에서 서보 2~3개로 분기하는 연결 방식 자체는 맞지만, 그 선이 +5 V라면 WAGO 이후 선도 주황색이 아니라 **빨간색으로 그립니다.**

## 6. PCA9685 연결

PCA9685는 이 프로젝트에서 서보의 고전류 전원을 공급하는 보드로 사용하지 않고 **PWM 신호 생성 보드**로 사용합니다.

```text
ESP32 3.3 V → PCA9685 VCC
ESP32 SDA    → PCA9685 SDA
ESP32 SCL    → PCA9685 SCL
GND 버스 G5 → PCA9685 GND

PCA9685 CH0/1/4/5/6/7/8/9/10 Signal
  → 각 서보의 노랑/주황 Signal
```

- PCA9685 `V+`를 서보 9개의 전원 공급 경로로 사용하지 않습니다.
- PCA9685 채널 헤더에서는 최종 배선상 Signal만 사용합니다.
- 서보 빨간선은 +5 V WAGO로, GND선은 GND WAGO로 따로 분리합니다.
- ESP32 GND, PCA9685 GND, LRS -V는 GND 버스를 통해 공통 기준을 가집니다.

## 8. 현재 DC 퓨즈 기준

현재 보유·사용 가능한 퓨즈 규격과 하드웨어 기록을 반영한 **조립·시험 기준값**입니다.

| 회로 | 퓨즈 | 부하 |
|---|---:|---|
| F1 | **5 A** | 목 MG996R ×2 |
| F2 | **10 A** | DS3218 ×2 |
| F3 | **5 A** | 팔 MG996R ×2 |
| F4 | **5 A** | MG90S ×3 |
| F5 | 미장착 | 예비 |
| F6 | 미장착 | 예비 |

- F2와 F4는 DS3218·MG90S의 실제 피크전류가 아직 확정되지 않았으므로 실측 후 다시 검토합니다.
- 퓨즈 정격은 단순히 모터를 보호하는 값이 아니라 배선과 하네스를 포함한 분기 보호 값입니다.
- 특히 서보 자체 리드선이나 연장선이 메인 분기선보다 가늘 수 있으므로 실제 선 굵기와 허용전류를 확인합니다.
- 퓨즈가 반복 단선되면 바로 더 큰 값으로 교체하지 않고 단락, 역극성, 기구 걸림, 스톨, 단자 접촉 불량, 전압강하와 피크전류를 먼저 확인합니다.

## 10. 조립 순서

1. AC 플러그를 완전히 분리합니다.
2. 0717-2SCQ의 LINE/LOAD/N/PE와 스위치·퓨즈 연속성을 측정합니다.
3. 0717 → LRS AC/L, AC/N, FG를 연결합니다.
4. LRS `+V` → 빨강 2.5SQ → 퓨즈박스 COMMON +를 연결합니다.
5. LRS `-V` → 검정 2.5SQ → GND 버스 MAIN을 연결합니다.
6. 퓨즈박스 실물에 F1~F6 라벨을 붙입니다.
7. GND 버스 실물에 G1~G6 라벨을 붙입니다.
8. F1~F4 출력에서 각 +5 V WAGO까지 분기선을 연결합니다.
9. G1~G4에서 각 GND WAGO까지 분기선을 연결합니다.
10. 각 서보의 빨간선은 해당 +5 V WAGO에 연결합니다.
11. 각 서보의 GND는 해당 GND WAGO에 연결합니다.
12. 각 서보 Signal은 `MOTORS.md`에 지정된 PCA9685 채널에 연결합니다.
13. G5 → PCA9685 GND, G6 → ESP32 GND를 연결합니다.
14. ESP32 3.3 V/SDA/SCL → PCA9685 VCC/SDA/SCL을 연결합니다.
15. F1=5 A, F2=10 A, F3=5 A, F4=5 A를 장착하고 F5/F6은 비웁니다.
16. 모든 노출 도체와 압착 상태를 확인하고 AC/DC/신호선을 정리해 고정합니다.

---

## 11. 최초 시험 순서

1. 모든 분기 퓨즈를 뺀 상태에서 +V/-V 단락 여부를 확인합니다.
2. FG와 C13 보호접지 PE 연속성을 확인합니다.
3. 서보를 연결하지 않은 상태에서 LRS 무부하 출력이 약 5 V인지 측정합니다.
4. ESP32와 PCA9685 로직만 연결해 통신을 확인합니다.
5. F1을 장착하고 목 서보 1개 → 2개 순서로 시험합니다.
6. F2를 장착하고 DS3218 1개 → 2개 순서로 시험합니다.
7. F3를 장착하고 팔 MG996R 1개 → 2개 순서로 시험합니다.
8. F4를 장착하고 MG90S 1개 → 3개 순서로 시험합니다.
9. 각 단계에서 피크전류, 최저 5 V 레일 전압, 퓨즈·WAGO·단자·전선 발열을 기록합니다.
10. 실제 서비스 동작으로 목+팔 전체 반복 시험을 수행합니다.

즉시 전원을 차단할 조건:

- 냄새, 연기, 불꽃, 이상음
- 전선·WAGO·퓨즈·압착단자의 빠른 발열
- 퓨즈 반복 단선
- 5 V 레일의 큰 전압강하
- ESP32 재부팅, 심한 서보 떨림
- 기구 걸림 또는 서보 스톨

## 12. Fritzing 도면 작성 기준

최종 도면에서는 다음처럼 표현합니다.

```text

    ↓ 빨강
+5 V WAGO
    ↓ 빨강
서보 VCC

GND 버스 G1~G4
    ↓ 검정
GND WAGO
    ↓ 검정/갈색
서보 GND

PCA9685 CHx
    ↓ 노랑/주황
서보 Signal
```

**퓨즈박스 → WAGO → 여러 서보**로 분기하는 방식은 맞습니다. 단, +5 V 분기라면 WAGO 이후 서보까지의 선도 전원선이므로 빨간색으로 표시합니다. 주황/노랑은 PCA9685 Signal에만 사용합니다.

---

## 13. 금지 사항

- 서보 9개의 +5 V를 PCA9685 `V+` 또는 PCB 패턴을 통해 공급하지 않기
- 서보 고전류 GND를 PCA9685 채널 GND 헤더를 통해 귀환시키지 않기
- +5 V WAGO와 GND WAGO를 하나의 커넥터에 섞지 않기
- F5/F6 예비 회로에 불필요하게 퓨즈 장착하지 않기
- 퓨즈 대신 철사나 임의의 금속 사용하지 않기
- LRS-75-5와 LRS-150F-5 출력을 병렬 연결하지 않기
- FG와 -V를 임의로 연결하지 않기
- 전원이 연결된 상태에서 배선 변경하지 않기
- 맞지 않는 단자를 억지로 체결하지 않기
- WAGO에 납땜으로 굳힌 연선을 넣지 않기
- LRS 통풍구를 막거나 케이스를 분해하지 않기
