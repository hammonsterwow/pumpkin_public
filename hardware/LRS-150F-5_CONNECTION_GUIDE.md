# LRS-150F-5 연결 및 안전

MEAN WELL LRS-150F-5는 로봇의 서보 전용 5 V 전원공급장치로 사용한다.

> AC 입력 배선은 감전과 화재 위험이 있다. 전원이 분리된 상태에서 작업하고, 노출 단자가 없도록 절연·고정한다.

## 연결 구조

~~~text
AC 220 V
  → 0717-2SCQ 인렛(스위치·퓨즈)
  → LRS-150F-5 L / N / FG

LRS +V
  → 6구 퓨즈박스
  → F1 목 / F2 Root / F3 팔 / F4 손목·그리퍼

LRS -V
  → GND 버스바
  → 각 서보 GND / PCA9685 GND / Jetson GND
~~~

## 단자 연결

- L: 인렛의 Live
- N: 인렛의 Neutral
- FG: 보호접지와 금속 외함
- +V: 퓨즈박스 공통 입력
- -V: GND 버스바

서보 전원선은 퓨즈박스에서 분기하고, 신호선은 PCA9685 채널에 연결한다. PCA9685 로직 VCC와 서보용 5 V 전원은 구분한다.

## 설치 기준

- 전원공급장치는 통풍이 가능한 위치에 고정한다.
- AC와 DC 배선을 분리하고 케이블 글랜드 또는 스트레인 릴리프를 적용한다.
- 압착 단자는 전선 굵기와 단자 규격에 맞게 사용한다.
- 전원 인가 전 L/N/FG, +V/-V 극성과 단락 여부를 확인한다.
- 출력 전압 조정은 부하를 분리한 상태에서 진행한다.
- 최초 가동은 한 분기씩 연결하며 전압, 전류, 발열을 확인한다.

정상적인 전원 투입·차단 순서는 [SERVO_POWER_ON_OFF_MANUAL.md](./SERVO_POWER_ON_OFF_MANUAL.md)를 따른다.
