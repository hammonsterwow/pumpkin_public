## 최종 기구 조건

- 팔 1개, 목 2축
- 최종 서보 9개
- 팔: DS3218×2, MG996R×2, MG90S×3
- 목: MG996R×2

## 전체 AC 전원 구조

```text
외부 220 V AC
    │
    ▼
접지형·과부하 차단형 멀티탭
    ├── Jetson 정품 어댑터 → Jetson Orin Nano
    ├── MXW-10W2U → 5인치 HDMI LCD
    ├── QL010-0502000E → NEXT-UH308
    └── 접지형 C13 케이블
             │
             ▼
       Inalways 0717-2SCQ
          ├── LOAD L → 갈색 VCTF 0.75SQ → LRS AC/L
          ├── LOAD N → 파랑 VCTF 0.75SQ → LRS AC/N
          └── PE     → 녹/황 VCTF 0.75SQ → LRS FG
```

### AC 입력 단자

| 위치 | 전선 | 단자 |
|---|---|---|
| 0717-2SCQ 후면 | VCTF 0.75SQ | 4.8×0.8 mm 완전절연 암 평단자 |
| LRS AC/L·AC/N·FG | VCTF 0.75SQ | 1.25-3.5 절연 포크단자 |

- 0717-2SCQ는 L·N을 각각 퓨즈에 통과시킨 뒤 DPST 스위치로 함께 개폐합니다.
- PE는 스위치·퓨즈를 통과하지 않고 LRS FG로 연결합니다.
- 실제 LINE·LOAD·N·PE 경로는 무전원 상태의 연속성 측정으로 확인합니다.
- AC 퓨즈의 물리 크기·정격·시간지연 특성은 실물 확인 후 확정합니다.

## 서보 DC 분배

6구 ATO/ATC 퓨즈박스 중 F1~F4를 사용하고 F5~F6은 예비로 남깁니다.

```text
LRS-150F-5, 5 V / 22 A
    ├── +V
    │    └── 빨강 2.5SQ/AWG12
    │         └── 6구 공통입력형 ATO/ATC 퓨즈박스
    │              ├── F1 5 A  → 빨강 1.0SQ → 목 MG996R ×2 + WAGO
    │              ├── F2 10 A → 빨강 1.5SQ → DS3218 ×2 + WAGO
    │              ├── F3 5 A  → 빨강 1.0SQ → 팔 MG996R ×2 + WAGO
    │              ├── F4 5 A  → 빨강 1.0SQ → MG90S ×3 + WAGO
    │              ├── F5      → 예비, 퓨즈 미장착
    │              └── F6      → 예비, 퓨즈 미장착
    │
    └── -V
         └── 검정 2.5SQ/AWG12
              └── GND 버스
                   ├── 검정 1.0SQ → 목 MG996R ×2 GND WAGO
                   ├── 검정 1.5SQ → DS3218 ×2 GND WAGO
                   ├── 검정 1.0SQ → 팔 MG996R ×2 GND WAGO
                   ├── 검정 1.0SQ → MG90S ×3 GND WAGO
                   ├── 검정 0.5~0.75SQ → PCA9685 GND
                   └── 검정 0.5~0.75SQ → ESP32 GND
```

### 퓨즈 회로별 서보 ID

| 퓨즈 | 값 | 연결 서보 ID | PCA9685 채널 |
|---|---:|---|---|
| F1 | 5 A | `SERVO_MG996R_01`, `SERVO_MG996R_02` | CH0, CH1 |
| F2 | 10 A | `SERVO_DS3218_01`, `SERVO_DS3218_02` | CH4, CH5 |
| F3 | 5 A | `SERVO_MG996R_03`, `SERVO_MG996R_04` | CH6, CH7 |
| F4 | 5 A | `SERVO_MG90S_01`, `SERVO_MG90S_02`, `SERVO_MG90S_03` | CH8, CH9, CH10 |
| F5 | 미장착 | 예비 | - |
| F6 | 미장착 | 예비 | - |

현재 퓨즈값의 산정 근거와 실측 후 변경 조건은 `MOTORS.md`와 `power-budget.md`를 따릅니다.

## LRS·분배부 단자

| 연결 | LRS 측 | 분배부 측 |
|---|---|---|
| +V 메인 | 2.5-3.5 포크, M3.5 | 2.5-5 또는 2.5-6 링, 실물 스터드 대응 |
| -V 메인 | 2.5-3.5 포크, M3.5 | 2.5-5 또는 2.5-6 링, 실물 스터드 대응 |
| F1 목 분기 | - | 1.25-4 링 또는 실물 나사 대응 |
| F2 DS3218 분기 | - | 2-4/2.5-4 링 또는 실물 나사 대응 |
| F3 MG996R×2 분기 | - | 1.25-4 링 또는 실물 나사 대응 |
| F4 MG90S 분기 | - | 1.25-4 링 또는 실물 나사 대응 |
| 로직 GND | - | 1.25-4 링 또는 실물 나사 대응 |

F2 DS3218 분기는 1.5SQ/AWG14를 사용합니다. 실제 피크전류·전압강하·발열 시험 결과가 좋지 않으면 2.5SQ 또는 별도 분기로 재설계합니다.

## 서보 하네스

각 서보는 JR/Futaba 3핀 연장선을 가공해 전원과 신호를 분리합니다.

```text
연장선 신호선       → PCA9685 CHx Signal
연장선 빨간선       → 해당 퓨즈 분기 +5 V WAGO
연장선 갈색/검정선  → 해당 그룹 GND WAGO
```

- 원래 서보 케이블은 자르지 않습니다.
- PCA9685 V+와 PCB 패턴으로 서보 9개 전류를 공급하지 않습니다.
- PCA9685 채널 GND를 서보 고전류 귀환 경로로 사용하지 않습니다.
- 절단한 연장선 끝은 열수축 튜브로 절연하고 당김 방지를 적용합니다.

## ESP32·PCA9685·얼굴 LCD

```text
Jetson USB
    │ USB Serial 115200 baud + ESP32 로직 전원
    ▼
LOLIN D32
    ├── 3.3 V ───── PCA9685 VCC
    ├── SDA/SCL ─── PCA9685 I2C
    ├── SPI ─────── ILI9488 얼굴 LCD
    └── GND ─────── GND 버스 저전류 분기

PCA9685 GND ─────── GND 버스 저전류 분기
```

### ILI9488 얼굴 LCD 최종 8선 배선

| LCD 핀 | LOLIN D32 핀 | 용도 |
|---|---|---|
| `VCC` | `USB` | LCD 본체 5 V 전원 |
| `GND` | `GND` | 공통 접지 |
| `CS` | `GPIO15` | LCD Chip Select |
| `RESET` | `GPIO4` | LCD 하드웨어 리셋 |
| `DC/RS` | `GPIO2` | 데이터/명령 선택 |
| `SDI(MOSI)` | `GPIO23` | ESP32 → LCD SPI 데이터 |
| `SCK` | `GPIO18` | SPI 클럭 |
| `LED` | `3V` | 백라이트 전원 |

현재 화면 출력에서는 아래 핀을 연결하지 않습니다.

```text
SDO(MISO), T_CLK, T_CS, T_DIN, T_DO, T_IRQ
```

- 초기 계획의 LCD CS `GPIO5`는 LOLIN D32 내장 LED와 공유되므로 최종 배선에서 `GPIO15`로 변경했습니다.
- LCD `BAT` 전원은 사용하지 않습니다.
- 화면 드라이버는 ILI9488이며 가로 방향 480×320으로 사용합니다.
- TFT_eSPI 설정은 MOSI 23, SCK 18, CS 15, DC 2, RST 4, SPI 5 MHz입니다.
- ESP32 메인 펌웨어는 `robot_face/esp32_lcd/esp32_lcd_face.ino`입니다.
- ESP32는 USB Serial에서 `NEUTRAL`, `SMILE`, `HAPPY`, `QUESTION`, `ERROR` 명령을 받습니다.
- 2026-08-02 기준 단색 화면과 5종 표정 출력을 실제 확인했습니다.
- 임시 암-암 점퍼선은 LCD를 움직일 때 접촉 불량이 발생해 백라이트만 남을 수 있으므로 최종 조립 전 고정 커넥터 또는 납땜 배선으로 교체합니다.

보드 측 GND 커넥터와 전선 마감 방식은 실물 보드의 터미널·핀 규격을 확인한 뒤 확정합니다.

## 현재 적용 퓨즈값

| 회로 | 적용값 | 실측 후 재검토 기준 |
|---|---:|---|
| F1 목 MG996R×2 | **5 A** | 반복 단선·전압강하·발열 확인 |
| F2 DS3218×2 | **10 A** | 실제 보유 규격 반영, DS3218 실제 피크전류 측정 후 유지/변경 |
| F3 MG996R×2 | **5 A** | 기록된 stall current 합 2.8 A 대비 확인 |
| F4 MG90S×3 | **5 A** | 3 A 미보유로 사용 가능한 더 작은 규격 적용, MG90S 실제 피크전류 측정 후 유지 여부 확인 |
| F5 | 미장착 | 예비 |
| F6 | 미장착 | 예비 |

위 값은 현재 프로젝트 하드웨어 기록과 실제 사용 가능한 퓨즈 규격에 따른 조립 기준값입니다. 반복 단선 시 큰 퓨즈로 바로 교체하지 않고 단락, 기구 걸림, 피크전류, 전압강하와 단자 발열을 확인합니다.

## 설치 조건

- LRS 단자 M3.5, 체결 토크 8~10 kgf·cm
- 바닥 M3 나사 최대 삽입 3.0 mm
- 측면 M3 나사 최대 삽입 5 mm
- 표준 수평 방향 장착
- 통풍구 차단 금지
- 열원과 10~15 cm 이격 또는 별도 환기 설계
- AC와 DC·USB·I2C·PWM 배선 분리
- 노출 AC 단자와 +5 V 버스 차폐
- 금속 모서리에 부싱 적용
