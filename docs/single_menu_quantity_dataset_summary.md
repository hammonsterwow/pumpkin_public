# 단일 메뉴 수량 1~20 증강 데이터셋

## 목적

업로드된 `아이스 아메리카노 한잔.csv`의 문장 형식을 바탕으로, 단일 메뉴 주문의 메뉴·온도·수량 표현을 균형 있게 확장했다.

이 파일은 한 문장에 주문 항목이 하나만 포함된 `ORDER` 데이터다. 복합 주문은 포함하지 않는다.

## 생성 파일

| 파일 | 설명 |
|---|---|
| `data/source_ice_americano_quantity_1.csv.gz.b64` | 사용자가 제공한 원본 CSV를 gzip 후 base64로 저장한 파일 |
| `data/single_menu_quantity_1_20_augmented.csv.gz` | 최종 증강 데이터 32,000개를 gzip으로 압축한 스냅샷 |
| `data/single_menu_quantity_1_20_excluded.csv` | 전용 표현·중복으로 제외된 원본 행 |
| `data/single_menu_quantity_1_20_statistics.json` | 메뉴·온도·수량·별칭 분포와 검증 결과 |
| `scripts/generate_single_menu_quantity_dataset.py` | 동일 결과를 재생성하는 표준 라이브러리 기반 스크립트 |

## 원본 정제

업로드 파일은 헤더를 제외하면 267개 문장이다.

- 아메리카노 전용 축약어 `아아`: 23개 제외
- `커피`, `커피 물탄거`처럼 다른 메뉴에 공통 적용하기 어려운 표현: 2개 제외
- 공백 정규화 후 중복 문장: 42개 제외
- 최종 공통 템플릿: 200개

원본에서 의도적으로 포함한 구어체, 방언, 명령형 표현은 유지했다.

## 출력 스키마

```text
text,label,menu,temperature,quantity,memo
```

- `label`: 전부 `ORDER`
- `menu`: 대표 라벨로 통일
- `temperature`: `ICE` 또는 `HOT`
- `quantity`: 정수 `1`~`20`
- `memo`: 빈 문자열

## 메뉴와 별칭

| 대표 라벨 | 문장에 사용한 표현 | 허용 온도 |
|---|---|---|
| 아메리카노 | 아메리카노 | ICE, HOT |
| 카페라떼 | 카페라떼, 카페라테, 커피라떼 | ICE, HOT |
| 바닐라라떼 | 바닐라라떼, 바닐라라테, 바닐라떼 | ICE, HOT |
| 레몬에이드 | 레몬에이드, 레모네이드, 레몬 주스 | ICE |
| 딸기스무디 | 딸기스무디, 딸기 스무디, 딸기 주스, 스트로베리 스무디 | ICE |

레몬에이드와 딸기스무디의 HOT 데이터는 만들지 않았다.

## 온도 표현 변환

ICE 원문의 문장 구조를 유지하면서 HOT 버전은 다음과 같이 변환했다.

| ICE 표현 | HOT 표현 |
|---|---|
| 아이스 메뉴 | 핫 메뉴 |
| 메뉴 아이스로 | 메뉴 핫으로 |
| 아이스로 메뉴 | 핫으로 메뉴 |
| 차가운 메뉴 | 따뜻한 메뉴 |
| 시원한 메뉴 | 뜨거운 메뉴 |
| 차갑게 | 따뜻하게 |
| 시원하게 | 뜨겁게 |

서로 다른 원본 템플릿이 같은 HOT 문장으로 합쳐지지 않도록 표현을 구분했다.

## 수량 표현

원문의 네 가지 수량 형태를 유지하여 1~20으로 확장했다.

| 원본 형태 | 확장 예 |
|---|---|
| 한 잔 | 두 잔, 열한 잔, 스무 잔 |
| 한잔 | 두잔, 열한잔, 스무잔 |
| 하나 | 두 개, 열한 개, 스무 개 |
| 한개 | 두개, 열한개, 스무개 |

## 최종 분포

총 32,000개 문장을 생성했다.

### 메뉴·온도

8개 유효 조합을 각각 4,000개로 맞췄다.

| 메뉴 | 온도 | 문장 수 |
|---|---:|---:|
| 아메리카노 | ICE | 4,000 |
| 아메리카노 | HOT | 4,000 |
| 카페라떼 | ICE | 4,000 |
| 카페라떼 | HOT | 4,000 |
| 바닐라라떼 | ICE | 4,000 |
| 바닐라라떼 | HOT | 4,000 |
| 레몬에이드 | ICE | 4,000 |
| 딸기스무디 | ICE | 4,000 |

### 수량

각 수량은 전체 데이터에서 1,600번씩 등장한다.

```text
1: 1,600
2: 1,600
...
20: 1,600
```

각 `메뉴-온도-수량` 조합에는 200개의 문장이 있다.

## 재생성

저장소 루트에서 실행한다.

```bash
python3 scripts/generate_single_menu_quantity_dataset.py
```

외부 패키지가 필요하지 않으며 Python 표준 라이브러리만 사용한다.

원본 파일을 사람이 직접 확인하려면 다음과 같이 복원한다.

```bash
base64 -d data/source_ice_americano_quantity_1.csv.gz.b64 | gzip -d > /tmp/source_ice_americano_quantity_1.csv
```

저장소에 포함된 압축 스냅샷을 바로 사용할 때는 다음과 같이 푼다.

```bash
gzip -dk data/single_menu_quantity_1_20_augmented.csv.gz
```

## 학습 데이터 사용 주의

이 데이터는 하나의 원본 템플릿을 메뉴·온도·수량만 바꾸어 증강한 데이터다. 같은 템플릿 계열이 train과 valid/test에 동시에 포함되면 평가 점수가 실제 일반화 성능보다 높게 측정될 수 있다.

권장 방법은 다음 중 하나다.

1. 기존 train/valid/test를 유지하고 이 증강 파일은 train에만 추가한다.
2. 새로 분할해야 할 경우 원본 템플릿 단위로 그룹을 나누어 같은 템플릿 계열이 여러 split에 걸치지 않게 한다.
